# DevQuiz – Interactive Online Quiz Application

**Test Your Knowledge. Challenge Yourself. Keep Learning.**

## 📌 Project Overview

DevQuiz is an interactive online quiz application developed using HTML5, CSS3, and Vanilla JavaScript. It allows users to test their knowledge across multiple technical and general knowledge categories through an easy-to-use interface.

The application provides instant feedback, score calculation, answer review, and performance tracking to create an engaging learning experience.

## ✨ Features

- Multiple quiz categories
- 36 questions across 8 categories
- Dynamic question navigation
- Next and Previous question controls
- Question palette for quick navigation
- Progress tracking
- Clear answer option
- Submission confirmation
- Automatic score calculation
- Correct, incorrect, and unanswered answer statistics
- Answer review with explanations
- Best score tracking using Local Storage
- Retake quiz functionality
- Responsive user interface

## ⚙️ How to Run Locally

1. Clone or download the project repository.
2. Open the project folder in Visual Studio Code.
3. Open the terminal.
4. Run the following command:

```bash
python -m http.server 8080
```

5. Open your browser and visit:

```text
http://localhost:8080
```

## 🧪 Testing

The application can be tested by:

- Selecting different quiz categories.
- Attempting questions and navigating between them.
- Checking the question palette and progress indicator.
- Clearing selected answers.
- Submitting the quiz.
- Reviewing the final score and answer explanations.
- Retaking the quiz.
- Checking whether the best score is retained after refreshing the page.
